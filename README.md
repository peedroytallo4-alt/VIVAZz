# Vivaz — viva no seu ritmo

Site responsivo de apresentação e loja demonstrativa da Vivaz, feito com HTML, CSS e JavaScript puro.

## Estrutura

```text
.
├── index.html   # Conteúdo e estrutura da página
├── styles.css   # Estilos e adaptação para celulares
├── script.js    # Menu mobile, carrinho, cadastro, frete e checkout demonstrativo
└── README.md    # Informações do projeto
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os quatro arquivos acima para a raiz do repositório. O arquivo inicial deve continuar com o nome `index.html`.
3. Nas configurações do repositório, abra **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch principal e a pasta **/(root)**, e salve.
5. O GitHub Pages disponibilizará o endereço do site nessa mesma seção após a publicação.

## Observações

- O site não precisa de instalação de dependências nem de um servidor backend.
- O carrinho, o cadastro, o cálculo de frete e o checkout funcionam apenas como demonstração no navegador; nenhum pagamento é processado e os dados não são enviados nem armazenados.
- As fontes personalizadas são carregadas do Google Fonts. Se não estiverem disponíveis, serão usadas fontes de fallback.
